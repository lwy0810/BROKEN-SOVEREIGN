## 1. 개요

### 한 줄 소개

신들에게 격(格)을 빼앗긴 영웅이 신화들을 침공해 격을 되찾는 3D 쿼터뷰 핵앤슬래시

### 핵심 재미

1. **되찾는 성장**: 범인에서 태초까지, 빼앗긴 격을 한 단계씩 회복하는 성장
2. **영웅이 되어 가는 빌드**: 직업 선택 후 '투전성자', '바위에서 검을 뽑은 왕' 같은 신화 원형 영웅의 길을 이어받는 전직
3. **규칙이 바뀌는 강함**: 초월 단계부터 수치 증가가 아닌 기술 작동 방식 자체의 변화
4. **신을 쓰러뜨리는 쾌감**: 각 신화의 주신과 하위 신을 상대하는 보스전

### 차별점

| 비교 대상 | 공통점 | BROKEN SOVEREIGN의 차이 |
|---|---|---|
| 디아블로 시리즈 | 쿼터뷰 핵앤슬래시 | 직업 없이 시작해 첫 구역에서 직업 선택, 직업 위에 신화 영웅의 길을 얹는 2단 전직 |
| 갓 오브 워 | 신화 속 신과의 전투 | 한 신화가 아닌 동서양 4개 신화 권역 침공 |
| 웹소설 '격' 소재 | 격의 상승 | 격 단계마다 전직·슬롯·규칙 변화가 열리는 시스템화 |

## 2. 세계관

### 2.1 표면의 이야기

| 항목 | 내용 |
|---|---|
| 사건 | 메이저 신화의 주신들이 영웅들의 격을 수확하며 성장 |
| 주인공 | 격을 빼앗기고 필멸이 된 이름 없는 영웅 |
| 목표 | 신화 권역들을 침공해 수확당한 영웅들의 격 회복 |
| 분위기 | 신화적 다크 판타지. 빛을 잃은 신역과 균열 |

### 2.2 숨겨진 진실

- 신들의 격 수확 목적: 세계 밖의 존재 **외해(외신)**를 막는 방벽 유지
- 주인공의 격 회복 = 방벽 약화
- 후반 전개: 외해의 귀환 → 엔드게임 콘텐츠로 연결

### 2.3 권역

| 권역 | 주신 | 신화 | 소속 영웅 | 비고 |
|---|---|---|---|---|
| 천계 | 옥황상제 | 중국·동아시아 | 연화, 석천, 사일, 한월 | 첫 권역 고정 |
| 올림포스 | 제우스 | 그리스 | 드로메우스, 폴리트로스, 키네고스, 아이톤 | |
| 북방 | 오딘 | 북유럽 + 게르만·슬라브(넓은 범위) | 오름바네, 티호미르, 알브레흐트, 야로미르 | |
| 티르 나 노그 | 루 | 켈트 + 아서왕 전설·서유럽 | 가르브, 펜드란, 뒤렌, 모르비안 | |

- 영웅은 실존 신화·전설 인물을 원형으로 한 창작 인물 (4.2 명명 원칙). 주신·하위 신은 원전 실명

- 천계 이후 권역 진행 순서: 확정 필요
- 권역별 하위 신·권속 구성: 확정 필요 (후보: 북방 '불사의 코셰이', 올림포스 '전갈')

## 3. 격(格) 위계

|---|---|---|---|

### 3.1 격 돌파 조건

세 조건 모두 충족 시 돌파 가능

| 돌파 | 신물 보유 수 | 스탯 총합 | 주 스탯 최소 (총합의 40%) | 시련 업적 |
|---|---|---|---|---|
| 범인 → 초인 | 1 | 60 | 24 | 범인 시련 |
| 초인 → 반신 | 2 | 92 | 37 | 초인 시련 |
| 반신 → 신격 | 4 | 125 | 50 | 반신 시련 |
| 신격 → 초월 | 6 | 157 | 63 | 신격 시련 |
| 초월 → 태초 | 8 | 190 | 76 | 초월 시련 |

- 시작 스탯: 힘 10 / 민첩 10 / 지능 10 (총 30)
- 주 스탯 조건: 해당 단계 스탯 총합의 40% 이상 (소수점 올림)
- 격에 따른 레벨·스탯 상한: 없음

| 시련 | 형태 | 내용 |
|---|---|---|
| 범인 시련 | 전투 도전형 | 천계 정예 처치 |
| 초인 시련 | 전투 도전형 | 시련 방에서 제한 시간 내 적 무리 섬멸 |
| 반신 시련 이후 | - | 확정 필요 |

### 3.2 초월

초월 슬롯 3칸. 시련 업적 달성 시 한 칸씩 개방

| 단계 | 규칙 성격 | 예시 방향 |
|---|---|---|
| 초월 Ⅰ | 기술의 근본적인 작동 방식 변화 | 투사체 → 장판, 단일 → 연쇄 |
| 초월 Ⅱ | 능력의 융합 및 변질 | 두 기술의 효과 결합, 속성 변질 |
| 초월 Ⅲ | 세계의 법칙에 영향을 주는 특수 효과 | 시간·중력·지형 등 전장 규칙 변경 |

### 3.3 태초 궁극기

영웅의 길마다 2개 (액티브 1, 패시브 1)

| 구분 | 획득 | 성장 |
|---|---|---|
| 액티브 | 태초 도달 즉시 획득 (6번 키) | 태초의 정수로 5단계 강화. Ⅲ단계부터 초월 규칙과 연동 |
| 패시브 | 레시피 획득. 기존 능력을 재료로 창조 | 확정 필요 |

- 궁극기 내용: 영웅의 길별 개발자 직접 설계 (자동 생성 없음)

- 직업 선택 방식: 직업 없이 시작(무직 범인). 구역 1 초반 튜토리얼 전투 후 '빼앗긴 격의 잔재'와 조우, 1차 직업 4개 중 선택
- 무직 상태: 좌클릭 기본 공격·회피·물약 + 공용 기술 1개 (6.6 참고). 직업 자원·1·2번 슬롯 미개방
- 궁사 집중 충전 방식: 명사수는 원거리 적중·치명타, 사냥꾼은 표식 적중
- 주 스탯 배정: 성기사 힘 (확정) / 무사 힘·궁사 민첩·마법사 지능 (제안, 확정 필요)
- 영웅 공개 방식: 홍보물·One-page GDD에 영웅 이름 미노출. 반신 돌파 시 영웅의 길 선택 화면에서 첫 공개

### 4.2 영웅 선정 기준·명명 원칙

명명 원칙 (2026-10-14 변경)

- 실존 신화·전설·민담 인물은 **원형(레퍼런스)**으로만 사용. 이름·성물은 창작
- 실명·별명·아명 미사용. **칭호**로 원형 일화를 한 줄로 떠올리게 함
- 성물: 원전 고유명사(엑스칼리버, 여의봉 등) 미사용, 형태·일화만 반영
- 권역 주신(옥황상제·제우스·오딘·루)과 하위 신(이랑진군 등)은 원전 실명 유지

선정 기준

- 원형이 떠오르는가 (외형·성물·일화로 연상)
- 성물과 직업 무기의 연결
- 원형 출처: 신화·설화·전설·소설·민담. 실존 인물·역사 소설(삼국지 등) 제외
- 타 작품 고유 표현 배제 ("보구" 대신 "성물")
- 영웅 간 고유 메커니즘 중복 금지
- 영웅 간 전투 스타일 차별 (거리·대상·리듬·핵심 행동, 4.4 점검표)

| 연결 성장 루트 | 스킬 + 업적 |

### 5.5 스탯 효과

1차 스탯은 모든 직업에 같은 효과. 주 스탯만 추가로 피해 증가 (디아블로4 방식)

| 스탯 | 효과 | 계산 |
|---|---|---|
| 힘 | 방어력 (물리 피해 감소) | 1당 방어력 +1. 감소율 = 방어력 / (방어력 + 1000), 상한 85% |
| 민첩 | 공격 속도 | 0.5 × 민첩 / (민첩 + 1000), 최대 +50% |
| 지능 | 원소 저항 (원소 피해 감소) | 0.5 × 지능 / (지능 + 1000), 최대 +50% |
| 주 스탯 | 피해 증가 | 1당 +0.1% (무직은 주 스탯 없음) |

- 스탯 단위: 장비·신물 포함 수천 단위 가정. 수렴식으로 고스탯에서도 상한 이하 유지
- 원소 저항 상한: 70%. 상한 증가 능력치로 최대 85%

| 구분 | 2차 능력치 |
|---|---|
| 공격 | 공격력, 피해 증가(전체·물리·원소), 공격 속도, 치명타 확률(최대 100%), 치명타 피해(기본 +50%) |
| 방어 | 최대 체력, 초당 생명력 회복, 방어력, 원소 저항, 원소 저항 상한, 회피 확률, 피해 감소 |
| 유틸 | 이동 속도, 재사용 대기 감소, 자원 소모 감소, 물약 회복량 |

- 피해 공식: 공격력 × 기술 계수 × (1 + 피해 증가) × 주 스탯 배율 × 치명타 배율
- 받는 피해: 회피 판정 후 (방어력 또는 원소 저항)과 피해 감소를 곱셈으로 적용. 1 − (1 − 타입 감소)(1 − 피해 감소)
- 피해 감소·재사용 대기 감소: 여러 출처를 곱셈으로 쌓아 100% 도달 방지
- 기본값 관리: 캐릭터·적별 능력치 에셋(ScriptableObject). 같은 항목에 수치만 다르게 설정

- 카메라: 쿼터뷰 고정 각도, 플레이어 추적
- 원칙: 공격·시전 중 정지. 기본 공격·기술은 사거리 안에 들면 멈춰서 실행하고, 동작 시간(기본 공격 = 공격 간격, 기술 = 시전 시간) 동안 이동·다른 공격 불가. 회피로는 동작을 끊을 수 있음
- 기술 시전 동작 중 이동 입력: 동작을 끊지 않고 끝난 뒤 마지막 지점으로 이동. 기본 공격 동작은 이동 입력으로 바로 끊김
- 적 효과 표시: 몸 색을 바꾸지 않고 머리 위에 효과 이름(도발·전장의 함성·기절·공중·무력화 등)
- 예외: 휠윈드 등 이동 시전 기술(MoveWhileCasting)은 이동하며 시전
- 회피: 커서 방향 4m, 0.2초, 지속 시간 전체 무적, 재사용 대기 1초 (초안)
- 적 클릭 공격·시전: 사거리까지 추적 후 실행. 짧은 클릭은 1회, 누르고 있으면 반복. 바닥 이동·제자리 공격·회피 시 대상 해제
- 무직 상태 사용 가능 입력: 좌클릭(이동·기본 공격), Shift + 좌클릭, 우클릭(공용 기술), Space, Q

### 6.3 신앙 상세 (성기사)

- 설정: 신앙의 대상은 신이 아닌 빼앗긴 영웅들 (영웅 신앙). 성기사 = 잊힌 영웅들의 이름을 기억하겠다고 맹세한 자
- 근거: 고대 그리스의 신과 별개인 영웅 숭배 전통
- 성광(聖光) = 신의 빛이 아닌 영웅들의 격이 남긴 빛

모아서 쓰는 자원 + 충만 상태. 좌클릭 기본 공격·피격으로 충전, 기술 시전으로 소모

| 규칙 | 값 (초안, 밸런스 단계 조정) |
|---|---|
| 최대치 | 격 회복마다 +20 (아래 표) |
| 충전 | 기본 공격 적중 +5, 피격 +3 (고정) |
| 감소 | 비전투 시 초당 −5 |
| 소모 | 기술별 15~40 |
| 충만 | 현재 격의 최대치 도달 시 충만 상태. 다음 기술 1회 강화, 강화량은 소모한 신앙량 비례. 강화 후 신앙 전량 소모 |

| 격 | 범인 | 초인 | 반신 | 신격 | 초월 | 태초 |
|---|---|---|---|---|---|---|
| 신앙 최대치 | 100 | 120 | 140 | 160 | 180 | 200 |

- 격이 높을수록 충만 빈도는 낮아지고 위력은 커지는 구조. 회복된 격의 체감 장치
- 충만 빈도 보완: 기술 강화 분기·장비
- 비전투 판정 기준(마지막 공격·피격 후 경과 시간): 확정 필요

### 6.5 성투사·영웅의 길 기술 (프로토타입)

#### 성투사 3번 기술 (2차 직업 공통)

| 기술 | 내용 | 신앙 | 재사용 대기 |
|---|---|---|---|
| 격진(格震) | 양손 둔기로 땅을 내려찍어 원형 충격파 3회 연속 확산. 파동마다 범위 증가, 3번째 파동에 적중한 적 0.8초 띄우기 | −35 | 10초 |

- 충만 강화: 파동 5회 + 범위 증가
- 역할: 성기사 기술(단일·부채꼴 위주)에 없는 넓은 원형 범위 + 띄우기
- 중복 회피: 넉백(뒤렌) 대신 띄우기, 지속 장판(펜드란) 대신 순간 파동
- 3번 슬롯 후보 기술: 본 기획에서 추가 (프로토타입은 해금 이벤트 부족으로 제외)

#### 야로미르(철퇴의 순례자): 분쇄

원형: 러시아 영웅 서사시의 일리야 무로메츠. 오래 움직이지 못하던 자가 순례자에게 받은 힘으로 국경을 지키고, 싸움 끝에 성자의 칭호를 얻은 용사

패시브 「철퇴의 무게」: 플레이어의 모든 피해가 적의 **버팀 게이지**를 깎음. 0이 되면 **무력화**

| 규칙 | 값 (초안) |
|---|---|
| 버팀 게이지 | 일반 30 / 정예 100 / 보스 300 |
| 게이지 감소 | 적중 피해 계수 × 10 (기본 공격 10, 격광 강타 22, 격진 파동당 15) |
| 게이지 회복 | 3초간 감소가 없으면 초당 최대치의 10% 회복 |
| 무력화 | 행동 불능 3초 (보스 2초) + 받는 피해 +25%. 진행 중인 공격·예비 동작 취소 |
| 무력화 후 | 게이지 전량 회복, 10초간 다시 무력화되지 않음 (보스 저항) |
| 표시 | 정예·보스는 체력 막대 아래 버팀 막대, 무력화 시 금이 간 방패 표시 |

| 키 | 기술 | 내용 | 신앙 | 재사용 대기 |
|---|---|---|---|---|
| 4 | 분쇄 일격(粉碎一擊) | 전방 단일 대상 철퇴 내려찍기 (300%). **무력화된 대상이면 처형**: 600% + 주변 2.5m 파편 충격파 (150%) + 무력화 즉시 종료 | −30 | 10초 |

- 충만 강화: 무력화되지 않은 대상에게 적중하면 버팀 게이지 50% 즉시 감소
- 플레이 판단: 바로 쓰기(300%) vs 게이지를 깎아 무력화한 뒤 처형(600% + 충격파)
- 중복 회피: 진격의 맹세 기절은 고정 0.5초 즉시 효과 ↔ 무력화는 누적 보상 / 오름바네 대형 적 특화는 피해 증가형 ↔ 야로미르는 제어형 / 넉백(뒤렌) 미사용
- 구현 연결: 기존 기절 시스템(`IStunnable`·`StunTimer`) 확장. 버팀 게이지는 순수 클래스로 EditMode 테스트 대상
- 구현 (10/20): 게이지 최대치는 적 등급(일반·정예·보스, 적 정의)으로 결정. 면역 10초는 무력화가 끝난 시점부터. 처형하면 무력화 즉시 종료 후 면역 시작. 대상 프레임 체력 막대 아래 버팀 막대(정예·보스), 무력화 중 "무력화" 표시 (금이 간 방패 아이콘은 추후)
- 연출: 처형 시 금빛 균열이 땅을 가르는 내려찍기

#### 석천(투전성자): 사거리 전환

원형: 『서유기』 손오공. 제멋대로였던 힘이 싸움 끝에 성자의 칭호를 얻은 투사

| 단봉 (근거리) | 짧게 쥔 신봉 | 사거리 기본, 피해 ×1.3, 방어 관통 30% (대상 방어력 30% 무시) |

- 변경 이유 (10/15): 여의봉의 '늘어나는 봉'을 사거리로 보여 주되, 자동이 아닌 기술로 표현해 플레이어가 상황을 판단하게 함
- 연화와의 차이: 연화는 공격·방어 태세 전환(공방 축), 석천은 사거리·다중 타격 ↔ 근접 화력 전환(거리 축)
- 폴리트로스와의 차이: 폴리트로스는 원거리 투사체의 일직선 관통, 석천은 근거리 봉 휘두르기의 사거리 연장 다중 타격 (투사체 없음)

- 신앙 0 도달 시 종료

- 반경 증가: 기본 성능에 포함하지 않고 강화 분기로 제공 (밸런스 고려)
- 분기 방향 (제안): ① 여의 신장: 회전 유지 시간에 따라 반경 단계 증가 (최대 +1.5m) / ② 구름 타기: 이동 속도 감소 제거 + 유지 신앙 소모 감소

- 디아블로 휠윈드와의 차별: 원형 일화(천궁을 뒤엎은 소동) 기반, 금빛 봉 궤적·구름 이펙트 연출, 여의 분기 연동
- 원형 일화: 『서유기』 손오공이 천궁의 천병을 쓸어버린 대뇨천궁(大鬧天宮)

| 우클릭 | 잔향 강타(殘響强打) | 빼앗기고 남은 격의 흔적으로 내려치는 일격. 전방 짧은 범위 내려찍기 (150%) | 없음 | 4초 |

- 직업 선택 후: 우클릭 → 1차 직업 기본 기술 (성기사: 격광 강타), 1·2번 슬롯과 직업 자원 동시 개방
- 우클릭 슬롯 레벨: 공용 기술 사용 중에도 누적, 직업 기술로 교체 후 유지 (5.4 슬롯 단위 레벨 규칙)
- 역할: 직업 선택 전 전투 단조로움 완화, 직업 선택 시 기술·자원이 한꺼번에 열리는 체감 연출

### 7.2 격 수확 패턴

보스가 전투 중 격 결정을 이용해 스스로를 강화하는 패턴. 수확한 영웅의 격 종류와 무관하게 강화 내용 동일

| 보스 체력 | 결정 소환 | 미파괴 시 누적 강화 |
|---|---|---|
| 75% | 결정 1 | 공격력 +15% |
| 50% | 결정 2 | + 패턴 속도 +15% |
| 25% | 결정 3 | + 최대 체력 20% 보호막 |

- 결정 소환 후 10초 안에 파괴하지 못하면 보스가 흡수해 강화
- 파괴한 결정은 강화 단계에 포함되지 않음 (흡수한 결정 수 기준 강화)
- 플레이어 제재가 아닌 보스 강화 방식
- 프로토타입 적용 대상: 하위 신 (권속 적용 여부 확정 필요)

### 8.1 프로토타입 천계 구성

| 구역 | 구성 | 진행 |
|---|---|---|
| 구역 1 | 튜토리얼 전투 + 직업 선택 이벤트 + 전투 방 2~3 | 무직 시작 → 1차 직업 선택 → 범인 시련(정예 처치) → 초인 돌파 가능 |
| 구역 2 | 전투 방 2~3 + 권속 방 | 2차 직업(성투사) 기술 성장, 권속(우사·풍백) 처치 |
| 구역 3 | 전투 방 2~3 + 시련 방 | 초인 시련 → 반신 돌파, 영웅의 길 선택 |
| 보스 방 | 하위 신(이랑진군) | 격 수확 패턴 |

- 맵 구조 (2026-10-19 변경, 같은 날 계곡으로 재변경): 1km 오픈 필드 1장 + 보스 방 별도 씬. 높은 산맥(최고 약 370m)으로 둘러싼 고원 계곡 분지(참고: 티베트 계곡), 길 주변은 초원 계곡, 여러 갈래 자갈 강 2줄기(본류·지류), 길이 강을 지나는 곳만 얕은 여울·협곡은 석판 다리. 산·강은 진입 불가(걷기 영역으로만 NavMesh 생성). 오른쪽 위 정사각형 미니맵(주변 120m) + M 키 지도 화면. 가운데 마을(시작·NPC·웨이포인트), 남서쪽 구역 1(튜토리얼·직업 선택·전투 방 3·곁길 2·범인 시련), 북동쪽 구역 2(전투 방 4·곁길 1·협곡 석판 다리·반신 시련), 해안 절벽 위 보스 제단 → 보스 방. 길 사이는 산줄기로 막힌 골짜기 길 (디아블로4식 지형)
- 마을 (2026-10-19 재구성, 참고: 디아블로4 마을 지도): 성벽으로 둘러싼 124m 정사각형. 가운데 원형 광장(웨이포인트·석주·석등) → 광장 둘레길 → 동서남북 큰길과 성문 4개(서문·남문 → 구역 1, 북문·동문 → 구역 2) → 안쪽 네모 길·성벽 안쪽 길·대각선 길. 길 사이 구역은 집으로 채움. 길은 돌바닥, 구역은 다진 흙
- 지도 (2026-10-19 변경): 양피지 색조(디아블로4 지도 느낌), 길은 밝게, 갈 수 없는 산·강은 어둡게, 마을은 길·건물 자리·성벽을 세부 그림으로 표시. 오른쪽 위 정사각형 미니맵(주변 120m, 얇은 금테). M 키 = 지도 화면: 기본 전체 화면(게임 입력 차단, 휠 확대·축소, 끌기 이동), 표시 방식 오버레이(반투명, 이동 가능) 선택 가능 (추후 시스템 설정으로 이동, 지금은 Tab·지도 화면 버튼). 처음 열 때 마을 안 = 마을 전체 폭(190m), 전투 지역 = 확대(260m). 상점 NPC 아이콘(잡화·대장간·치유소)은 확대했을 때만 표시 (보이는 폭 420m 이하), 맵 확장 대비 아이콘 종류별 표시 단계 설정
- 마우스 커서 (2026-10-19 추가): 기본 커서 + 상황별 커서(적 위 = 공격, NPC 위 = 대화, 입력 차단 중 = 기본). 레이어별 규칙을 설정 에셋에서 추가·변경
- 마을 상점 (2026-10-19 추가): 광장을 둘러싼 상점 3곳(건물 + NPC). F 키로 대화, 대화 중 전투 입력 차단. 건물 앞면 위쪽 가운데에 상점 종류 명판(글자 없는 금빛 아이콘: 잡화 = 주머니·항아리, 대장간 = 검·방패, 치유소 = 호리병·연꽃), 지붕 색과 같은 계열 바탕

| 상점 | NPC | 프로토타입 기능 |
|---|---|---|
| 잡화상 | 곽상 | 대사만 (거래는 재화 확정 후) |
| 대장간 | 철무 (대장장이) | 대사만 (장비 제외 범위, 11장) |
| 치유소 | 백련 (치유사) | 체력 전체 회복 + 물약 충전 (비용 없음) |

- 보스 구성: 권속 1 + 하위 신 1 (서브 보스 개념, 주신은 프로토타입 제외)
- 권속 배치(구역 2 끝): 제안
- 권속·하위 신: 7.3 참고
