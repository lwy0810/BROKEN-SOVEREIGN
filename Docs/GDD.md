## 1. 개요

### 한 줄 소개

신들에게 격(格)을 빼앗긴 영웅이 신화들을 침공해 격을 되찾는 3D 쿼터뷰 핵앤슬래시

### 핵심 재미

1. **되찾는 성장**: 범인에서 태초까지, 빼앗긴 격을 한 단계씩 회복하는 성장
2. **영웅이 되어 가는 빌드**: 직업 선택 후 쿠훌린·아서왕·손오공 같은 신화 영웅의 길을 이어받는 전직
3. **규칙이 바뀌는 강함**: 초월 단계부터 수치 증가가 아닌 기술 작동 방식 자체의 변화
4. **신을 쓰러뜨리는 쾌감**: 각 신화의 주신과 하위 신을 상대하는 보스전

### 차별점

| 비교 대상 | 공통점 | BROKEN SOVEREIGN의 차이 |
|---|---|---|
| 디아블로 시리즈 | 쿼터뷰 핵앤슬래시 | 직업 없이 시작해 첫 구역에서 직업 선택, 직업 위에 신화 영웅의 길을 얹는 2단 전직 |
| 갓 오브 워 | 신화 속 신과의 전투 | 한 신화가 아닌 동서양 4개 신화 권역 침공 |
| 웹소설 '격' 소재 | 격의 상승 | 격 단계마다 전직·슬롯·규칙 변화가 열리는 시스템화 |

## 2. 세계관

### 2.1 표면의 이야기

| 항목 | 내용 |
|---|---|
| 사건 | 메이저 신화의 주신들이 영웅들의 격을 수확하며 성장 |
| 주인공 | 격을 빼앗기고 필멸이 된 이름 없는 영웅 |
| 목표 | 신화 권역들을 침공해 수확당한 영웅들의 격 회복 |
| 분위기 | 신화적 다크 판타지. 빛을 잃은 신역과 균열 |

### 2.2 숨겨진 진실

- 신들의 격 수확 목적: 세계 밖의 존재 **외해(외신)**를 막는 방벽 유지
- 주인공의 격 회복 = 방벽 약화
- 후반 전개: 외해의 귀환 → 엔드게임 콘텐츠로 연결

### 2.3 권역

| 권역 | 주신 | 신화 | 소속 영웅 | 비고 |
|---|---|---|---|---|
| 천계 | 옥황상제 | 중국·동아시아 | 목란, 손오공, 예, 항아 | 첫 권역 고정 |
| 올림포스 | 제우스 | 그리스 | 아킬레우스, 헤라클레스, 오디세우스, 오리온, 파에톤 | |

| 티르 나 노그 | 루 | 켈트 + 아서왕 전설·서유럽 | 쿠훌린, 아서왕, 롤랑, 멀린 | |

- 1차 직업 4 / 2차 직업 8 / 영웅의 길 16
- 직업 선택 방식: 직업 없이 시작(무직 범인). 구역 1 초반 튜토리얼 전투 후 '빼앗긴 격의 잔재'와 조우, 1차 직업 4개 중 선택
- 무직 상태: 좌클릭 기본 공격·회피·물약 + 공용 기술 1개 (6.6 참고). 직업 자원·1·2번 슬롯 미개방
- 궁사 집중 충전 방식: 명사수는 원거리 적중·치명타, 사냥꾼은 표식 적중
- 주 스탯 배정: 성기사 힘 (확정) / 무사 힘·궁사 민첩·마법사 지능 (제안, 확정 필요)
- 영웅 공개 방식: 홍보물·One-page GDD에 영웅 이름 미노출. 반신 돌파 시 영웅의 길 선택 화면에서 첫 공개

### 4.2 영웅 선정 기준

- 국내 인지도
- 성물과 직업 무기의 연결
- 출처: 신화·설화·전설·소설·민담. 실존 인물·역사 소설(삼국지 등) 제외
- 처음부터 신인 존재·현재 신앙 대상 제외. 반신·사후 신격화 영웅 허용
- 원전 명칭과 설정만 사용. 타 작품 고유 표현 배제 ("보구" 대신 "성물")
- 영웅 간 고유 메커니즘 중복 금지

### 5.1 신물

| 항목 | 내용 |
|---|---|
| 신물창 구성 | 중앙의 군주의 유물(별도 칸) + 격에 따라 열리는 칸 |
| 일반 장비와의 관계 | 같은 부위에 겹쳐 착용. 일반 장비 = 능력치, 신물 = 고유 효과·신화 세트 |
| 신화 세트 | 같은 신화 출신 신물 동시 장착 시 세트 효과 |
| 태초 신물 | 태초의 결정으로 승급. 최대 2개 장착 |
| 획득처 | 프로토타입: 아래 표 / 본 기획: 확정 필요 (보스·권속 처치, 시련 보상 후보) |

| 격 | 새로 열리는 칸 | 부위 | 신물 효과 성격 | 누적 칸 수 (유물 제외) |
|---|---|---|---|---|
| 범인 | 방어구 1 | 갑옷 | 생존 (피해 감소, 체력) | 1 |
| 초인 | 방어구 2 | 장신구 | 자원 (신앙 충전·소모) | 2 |
| 반신 | 무기 | 영웅 성물 전용 | 영웅의 길, 기술 변형 | 3 |
| 신격 | 방어구 3 | 장갑 | 기술 강화 (피해, 재사용 대기) | 4 |
| 초월 | 방어구 4 | 신발 | 이동·회피 | 5 |
| 태초 | 방어구 5 | 투구 | 격·궁극기 관련 | 6 |

- 부위 순서 근거: 초반 생존 → 기술 증가 시점의 자원 관리 → 각성 시점의 공격 강화 → 초월 시점의 기동력 → 태초에 관(冠) 회복. 부서진 군주가 다시 관을 쓰는 서사
- 신물 방어구 대상: 투구·갑옷·장갑·신발·장신구 5부위 (일반 장비 장신구 2칸 중 1칸에만 신물 겹침)
- 프로토타입 신물 칸(갑옷·장신구)이 프로토타입 일반 장비(무기·갑옷·장신구)와 겹쳐 '같은 부위 겹쳐 착용' 구조 시연 가능

프로토타입 신물 획득처

| 획득처 | 신물 | 시점 |
|---|---|---|
| 천계 정예 처치 (범인 시련) | 갑옷 신물 1 | 초인 돌파 직전 |
| 우사·풍백 처치 (권속) | 장신구 신물 1 | 반신 돌파 전 |

- 성물 기술 변형 범위: 본 기획은 장착 기술 전체, 프로토타입은 좌클릭·우클릭 기술 3개 이펙트 교체만 (영웅 2명 × 3 = 6)

### 5.4 기술 빌드 (격 회복형)

키마다 후보 기술 중 1개 장착 + 기술 레벨 강화 분기. 후보 기술은 레벨이 아닌 격 회복 과정(시련·보스 처치)에서 해금

| 항목 | 내용 |
|---|---|
| 후보 기술 | 키(슬롯)마다 2~3개. 1개 장착 |
| 후보 해금 | 시련 업적 달성, 권속·하위 신 처치 보상. 신에게 빼앗긴 기술을 되찾는 설정 |
| 스킬 포인트 | 레벨업당 1 (스탯 3포인트와 별도) |
| 기술 레벨 | 슬롯(키) 단위로 쌓임. 기술을 교체해도 슬롯 레벨 유지 |
| 강화 분기 | 슬롯 레벨 3·6에서 분기 택1 (제안). 분기 선택은 기술별로 저장 (교체 후 복귀 시 이전 선택 유지) |
| 분기 재선택 | 비전투 시 가능. 프로토타입은 무료, 본 기획 비용 여부 확정 필요 |
| 포인트 재분배 | 슬롯 레벨 공유 구조라 별도 기능 없음 |
| 연결 성장 루트 | 스킬 + 업적 |

- 차별점: 디아블로식 레벨 포인트 해금이 아닌 '되찾는 성장'과 연결된 해금 구조
- UI·아이콘·기술 이름은 타 게임과 유사하지 않게 제작

### 5.5 스탯 효과

1차 스탯은 모든 직업에 같은 효과. 주 스탯만 추가로 피해 증가 (디아블로4 방식)

| 스탯 | 효과 | 계산 |
|---|---|---|
| 힘 | 방어력 (물리 피해 감소) | 1당 방어력 +1. 감소율 = 방어력 / (방어력 + 1000), 상한 85% |
| 민첩 | 공격 속도 | 0.5 × 민첩 / (민첩 + 1000), 최대 +50% |
| 지능 | 원소 저항 (원소 피해 감소) | 0.5 × 지능 / (지능 + 1000), 최대 +50% |
| 주 스탯 | 피해 증가 | 1당 +0.1% (무직은 주 스탯 없음) |

- 스탯 단위: 장비·신물 포함 수천 단위 가정. 수렴식으로 고스탯에서도 상한 이하 유지
- 원소 저항 상한: 70%. 상한 증가 능력치로 최대 85%

| 구분 | 2차 능력치 |
|---|---|
| 공격 | 공격력, 피해 증가(전체·물리·원소), 공격 속도, 치명타 확률(최대 100%), 치명타 피해(기본 +50%) |
| 방어 | 최대 체력, 초당 생명력 회복, 방어력, 원소 저항, 원소 저항 상한, 회피 확률, 피해 감소 |
| 유틸 | 이동 속도, 재사용 대기 감소, 자원 소모 감소, 물약 회복량 |

- 피해 공식: 공격력 × 기술 계수 × (1 + 피해 증가) × 주 스탯 배율 × 치명타 배율
- 받는 피해: 회피 판정 후 (방어력 또는 원소 저항)과 피해 감소를 곱셈으로 적용. 1 − (1 − 타입 감소)(1 − 피해 감소)
- 피해 감소·재사용 대기 감소: 여러 출처를 곱셈으로 쌓아 100% 도달 방지
- 기본값 관리: 캐릭터·적별 능력치 에셋(ScriptableObject). 같은 항목에 수치만 다르게 설정

## 6. 전투

### 6.1 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 | 이동 / 기본 공격 (적 클릭 시 사거리까지 추적 후 공격) |
| Shift + 좌클릭 | 제자리 공격 |
| 우클릭 | 주력 기술. 사거리 밖이면 커서 지점(적 클릭 시 적)까지 이동 후 멈춰서 시전, 누르고 있으면 반복 시전 |
| 1, 2 | 1차 직업 기술 (직업 선택 후 개방) |
| 3 | 2차 직업 기술 |
| 4 | 영웅의 길 기술 |
| 5 | 각성 |
| 6 | 태초 궁극기 |
| Space | 회피 (커서 방향) |
| Q | 물약 |

- 이동: 클릭 이동 (디아블로·타이탄 퀘스트 방식)
- 카메라: 쿼터뷰 고정 각도, 플레이어 추적
- 원칙: 공격·시전 중 정지. 기본 공격·기술은 사거리 안에 들면 멈춰서 실행하고, 동작 시간(기본 공격 = 공격 간격, 기술 = 시전 시간) 동안 이동·다른 공격 불가. 회피로는 동작을 끊을 수 있음
- 예외: 휠윈드 등 이동 시전 기술(MoveWhileCasting)은 이동하며 시전
- 회피: 커서 방향 4m, 0.2초, 지속 시간 전체 무적, 재사용 대기 1초 (초안)
- 적 클릭 공격·시전: 사거리까지 추적 후 실행. 짧은 클릭은 1회, 누르고 있으면 반복. 바닥 이동·제자리 공격·회피 시 대상 해제
- 무직 상태 사용 가능 입력: 좌클릭(이동·기본 공격), Shift + 좌클릭, 우클릭(공용 기술), Space, Q

### 6.3 신앙 상세 (성기사)

- 설정: 신앙의 대상은 신이 아닌 빼앗긴 영웅들 (영웅 신앙). 성기사 = 잊힌 영웅들의 이름을 기억하겠다고 맹세한 자
- 근거: 고대 그리스의 신과 별개인 영웅 숭배 전통
- 성광(聖光) = 신의 빛이 아닌 영웅들의 격이 남긴 빛

모아서 쓰는 자원 + 충만 상태. 좌클릭 기본 공격·피격으로 충전, 기술 시전으로 소모

| 규칙 | 값 (초안, 밸런스 단계 조정) |
|---|---|
| 최대치 | 격 회복마다 +20 (아래 표) |
| 충전 | 기본 공격 적중 +5, 피격 +3 (고정) |
| 감소 | 비전투 시 초당 −5 |
| 소모 | 기술별 15~40 |
| 충만 | 현재 격의 최대치 도달 시 충만 상태. 다음 기술 1회 강화, 강화량은 소모한 신앙량 비례. 강화 후 신앙 전량 소모 |

| 격 | 범인 | 초인 | 반신 | 신격 | 초월 | 태초 |
|---|---|---|---|---|---|---|
| 신앙 최대치 | 100 | 120 | 140 | 160 | 180 | 200 |

- 격이 높을수록 충만 빈도는 낮아지고 위력은 커지는 구조. 회복된 격의 체감 장치
- 충만 빈도 보완: 기술 강화 분기·장비
- 비전투 판정 기준(마지막 공격·피격 후 경과 시간): 확정 필요

### 6.4 성기사 기술

| 보스 체력 | 결정 소환 | 미파괴 시 누적 강화 |
|---|---|---|
| 75% | 결정 1 | 공격력 +15% |
| 50% | 결정 2 | + 패턴 속도 +15% |
| 25% | 결정 3 | + 최대 체력 20% 보호막 |

- 결정 소환 후 10초 안에 파괴하지 못하면 보스가 흡수해 강화
- 파괴한 결정은 강화 단계에 포함되지 않음 (흡수한 결정 수 기준 강화)
- 플레이어 제재가 아닌 보스 강화 방식
- 프로토타입 적용 대상: 하위 신 (권속 적용 여부 확정 필요)

## 12. 기술 설계 방향

| 원칙 | 내용 |
|---|---|
| 데이터 중심 | 직업·영웅의 길·기술·신물·장비·적 수치는 ScriptableObject 정의. 코드 수정 없는 추가·조정 구조 |
| 규칙 분리 | 영웅 고유 메커니즘·초월 규칙은 전투 이벤트(피해, 처치, 상태이상)를 구독하는 규칙 객체. 전투 코드에 영웅별 분기 금지 |
| 순수 계산 | 피해·돌파 조건·자원 계산은 MonoBehaviour 밖 순수 클래스. EditMode 테스트 대상 |
| 이벤트 연결 | 전투 → 성장 시스템은 이벤트로만 연결. 예외: 시전 전 수치 변경(손오공 여의 등)은 `ISkillParameterModifier` 연결 지점 사용 (이벤트는 사후 통지라 시전 전 개입 불가) |

- 클래스 구조: `Docs/ClassDiagram.md` 참고
