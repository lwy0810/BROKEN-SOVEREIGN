## 1. 개요

### 한 줄 소개

신들에게 격(格)을 빼앗긴 영웅이 신화들을 침공해 격을 되찾는 3D 쿼터뷰 핵앤슬래시

### 핵심 재미

1. **되찾는 성장**: 범인에서 태초까지, 빼앗긴 격을 한 단계씩 회복하는 성장
2. **영웅이 되어 가는 빌드**: 직업 선택 후 쿠훌린·아서왕·손오공 같은 신화 영웅의 길을 이어받는 전직
3. **규칙이 바뀌는 강함**: 초월 단계부터 수치 증가가 아닌 기술 작동 방식 자체의 변화
4. **신을 쓰러뜨리는 쾌감**: 각 신화의 주신과 하위 신을 상대하는 보스전

### 차별점

| 비교 대상 | 공통점 | BROKEN SOVEREIGN의 차이 |
|---|---|---|
| 디아블로 시리즈 | 쿼터뷰 핵앤슬래시, 시작 직업 선택 | 직업 위에 신화 영웅의 길을 얹는 2단 전직 |
| 갓 오브 워 | 신화 속 신과의 전투 | 한 신화가 아닌 동서양 4개 신화 권역 침공 |
| 웹소설 '격' 소재 | 격의 상승 | 격 단계마다 전직·슬롯·규칙 변화가 열리는 시스템화 |

## 2. 세계관

### 2.1 표면의 이야기

| 항목 | 내용 |
|---|---|
| 사건 | 메이저 신화의 주신들이 영웅들의 격을 수확하며 성장 |
| 주인공 | 격을 빼앗기고 필멸이 된 이름 없는 영웅 |
| 목표 | 신화 권역들을 침공해 수확당한 영웅들의 격 회복 |
| 분위기 | 신화적 다크 판타지. 빛을 잃은 신역과 균열 |

### 2.2 숨겨진 진실

- 신들의 격 수확 목적: 세계 밖의 존재 **외해(외신)**를 막는 방벽 유지
- 주인공의 격 회복 = 방벽 약화
- 후반 전개: 외해의 귀환 → 엔드게임 콘텐츠로 연결

### 2.3 권역

| 권역 | 주신 | 신화 | 소속 영웅 | 비고 |
|---|---|---|---|---|
| 천계 | 옥황상제 | 중국·동아시아 | 목란, 손오공, 예, 항아 | 첫 권역 고정 |
| 올림포스 | 제우스 | 그리스 | 아킬레우스, 헤라클레스, 오디세우스, 오리온, 파에톤 | |

### 3.1 격 돌파 조건

세 조건 모두 충족 시 돌파 가능

| 돌파 | 신물 보유 수 | 스탯 총합 | 주 스탯 최소 (총합의 40%) | 시련 업적 |
|---|---|---|---|---|
| 범인 → 초인 | 1 | 60 | 24 | 범인 시련 |
| 초인 → 반신 | 2 | 92 | 37 | 초인 시련 |
| 반신 → 신격 | 4 | 125 | 50 | 반신 시련 |
| 신격 → 초월 | 6 | 157 | 63 | 신격 시련 |
| 초월 → 태초 | 8 | 190 | 76 | 초월 시련 |

- 시작 스탯: 힘 10 / 민첩 10 / 정신 10 (총 30)
- 주 스탯 조건: 해당 단계 스탯 총합의 40% 이상 (소수점 올림)
- 격에 따른 레벨·스탯 상한: 없음

| 시련 | 형태 | 내용 |
|---|---|---|
| 범인 시련 | 전투 도전형 | 천계 정예 처치 |
| 초인 시련 | 전투 도전형 | 시련 방에서 제한 시간 내 적 무리 섬멸 |

### 3.2 초월

초월 슬롯 3칸. 시련 업적 달성 시 한 칸씩 개방

| 단계 | 규칙 성격 | 예시 방향 |
|---|---|---|
| 초월 Ⅰ | 기술의 근본적인 작동 방식 변화 | 투사체 → 장판, 단일 → 연쇄 |
| 초월 Ⅱ | 능력의 융합 및 변질 | 두 기술의 효과 결합, 속성 변질 |
| 초월 Ⅲ | 세계의 법칙에 영향을 주는 특수 효과 | 시간·중력·지형 등 전장 규칙 변경 |

### 3.3 태초 궁극기

영웅의 길마다 2개 (액티브 1, 패시브 1)

| 구분 | 획득 | 성장 |
|---|---|---|
| 액티브 | 태초 도달 즉시 획득 (6번 키) | 태초의 정수로 5단계 강화. Ⅲ단계부터 초월 규칙과 연동 |
| 패시브 | 레시피 획득. 기존 능력을 재료로 창조 | 확정 필요 |

- 궁극기 내용: 영웅의 길별 개발자 직접 설계 (자동 생성 없음)

### 4.2 영웅 선정 기준

- 국내 인지도
- 성물과 직업 무기의 연결
- 출처: 신화·설화·전설·소설·민담. 실존 인물·역사 소설(삼국지 등) 제외
- 처음부터 신인 존재·현재 신앙 대상 제외. 반신·사후 신격화 영웅 허용
- 원전 명칭과 설정만 사용. 타 작품 고유 표현 배제 ("보구" 대신 "성물")
- 영웅 간 고유 메커니즘 중복 금지

## 5. 성장 루트

| 루트 | 내용 |
|---|---|
| 스탯 | 힘·민첩·정신. 레벨당 3포인트 분배 |

### 5.1 신물

| 항목 | 내용 |
|---|---|
| 신물창 구성 | 중앙의 군주의 유물(별도 칸) + 격에 따라 열리는 칸 |
| 일반 장비와의 관계 | 같은 부위에 겹쳐 착용. 일반 장비 = 능력치, 신물 = 고유 효과·신화 세트 |
| 신화 세트 | 같은 신화 출신 신물 동시 장착 시 세트 효과 |
| 태초 신물 | 태초의 결정으로 승급. 최대 2개 장착 |
| 획득처 | 확정 필요 (보스·권속 처치, 시련 보상 후보) |

| 격 | 새로 열리는 칸 | 누적 칸 수 (유물 제외) |
|---|---|---|
| 범인 | 방어구 1 | 1 |
| 초인 | 방어구 2 | 2 |
| 반신 | 무기 (영웅 성물 전용) | 3 |
| 신격 | 방어구 3 | 4 |
| 초월 | 방어구 4 | 5 |
| 태초 | 방어구 5 | 6 |

- 무기 칸: 반신에서 영웅의 길 선택과 함께 개방. 해당 영웅의 성물(예: 여의봉, 네메아의 사자 가죽 + 곤봉) 장착
- 칸 수가 돌파 조건의 신물 보유 수보다 적은 구조 → 보유 신물 중 장착할 신물 선택
- 방어구 칸별 부위(개방 순서): 확정 필요

### 5.4 기술 빌드 (격 회복형)

키마다 후보 기술 중 1개 장착 + 기술 레벨 강화 분기. 후보 기술은 레벨이 아닌 격 회복 과정(시련·보스 처치)에서 해금

| 항목 | 내용 |
|---|---|
| 후보 기술 | 키(슬롯)마다 2~3개. 1개 장착 |
| 후보 해금 | 시련 업적 달성, 권속·하위 신 처치 보상. 신에게 빼앗긴 기술을 되찾는 설정 |
| 스킬 포인트 | 레벨업당 1 (스탯 3포인트와 별도) |
| 기술 레벨 | 슬롯(키) 단위로 쌓임. 기술을 교체해도 슬롯 레벨 유지 |
| 강화 분기 | 슬롯 레벨 3·6에서 분기 택1 (제안). 분기 선택은 기술별로 저장 (교체 후 복귀 시 이전 선택 유지) |
| 분기 재선택 | 비전투 시 가능. 프로토타입은 무료, 본 기획 비용 여부 확정 필요 |
| 포인트 재분배 | 슬롯 레벨 공유 구조라 별도 기능 없음 |
| 연결 성장 루트 | 스킬 + 업적 |

- 차별점: 디아블로식 레벨 포인트 해금이 아닌 '되찾는 성장'과 연결된 해금 구조
- UI·아이콘·기술 이름은 타 게임과 유사하지 않게 제작

#### 프로토타입 적용 (축소판)

| 슬롯 | 기본 기술 | 두 번째 후보 해금 조건 |
|---|---|---|
| 좌클릭 | 고정 | - |
| 우클릭 | 기본 1 | 범인 시련 (정예 처치) |
| 1 | 기본 1 | 권속 (우사·풍백) 처치 |
| 2 | 기본 1 | 초인 시련 |

- 성기사 기술 4 → 7개
- 강화 분기: 우클릭 슬롯만 적용 (기본·후보 기술 각 2분기, 레벨 3 분기만 → 분기 데이터 4개)
- 분기 재선택: 비전투 시 무료
- 하위 신(이랑진군)은 최종 보스라 해금 보상 제외

## 6. 전투

### 6.1 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 | 이동 / 기본 공격 (적 클릭 시) |
| Shift + 좌클릭 | 제자리 공격 |
| 우클릭 | 주력 기술 |
| 1, 2 | 1차 직업 기술 |
| 3 | 2차 직업 기술 |
| 4 | 영웅의 길 기술 |
| 5 | 각성 |
| 6 | 태초 궁극기 |
| Space | 회피 (커서 방향) |
| Q | 물약 |

- 이동: 클릭 이동 (디아블로·타이탄 퀘스트 방식)
- 카메라: 쿼터뷰 고정 각도, 플레이어 추적
- 원칙: 정지 상태 강요 금지. 궁사·마법사 포함 전 직업 이동 중 공격·시전 가능

### 6.2 자원

| 직업 | 자원 | 충전 |
|---|---|---|
| 무사 | 투기 | 확정 필요 |
| 성기사 | 신앙 | 기본 공격 적중 + 피격. 앞에 나서서 싸우는 근접 플레이 유도 |
| 궁사 | 집중 | 명사수: 원거리 적중·치명타 / 사냥꾼: 표식 적중 |
| 마법사 | 마나 | 확정 필요 (파우스트는 마나 대신 채무) |

### 6.3 신앙 상세 (성기사)

모아서 쓰는 자원 + 충만 상태. 좌클릭 기본 공격·피격으로 충전, 기술 시전으로 소모

| 규칙 | 값 (초안, 밸런스 단계 조정) |
|---|---|
| 최대치 | 100 |
| 충전 | 기본 공격 적중 +5, 피격 +3 |
| 감소 | 비전투 시 초당 −5 |
| 소모 | 기술별 15~40 (기술 상세 단계에서 확정) |
| 충만 | 신앙 100 도달 시 충만 상태. 다음 기술 1회 강화(범위·피해 증가, 성광 연출) 후 신앙 전량 소모 |

- 비전투 판정 기준(마지막 공격·피격 후 경과 시간): 확정 필요

## 7. 적

### 7.1 등급

| 등급 | 역할 |
|---|---|
| 일반 | 무리 단위 등장. 쓸어 담는 대상 |
| 정예 | 고유 패턴 보유 |
| 챔피언 | 무작위 변이 부여 |
| 권속 | 권역 중간 보스 |
| 하위 신 | 권역 주요 보스 |
| 주신 | 권역 최종 보스 |
| 외신 | 엔드게임 적 |

### 7.2 격 수확 패턴

보스가 전투 중 격 결정을 이용해 스스로를 강화하는 패턴. 수확한 영웅의 격 종류와 무관하게 강화 내용 동일

| 보스 체력 | 결정 소환 | 미파괴 시 누적 강화 |
|---|---|---|
| 75% | 결정 1 | 공격력 +15% |
| 50% | 결정 2 | + 패턴 속도 +15% |
| 25% | 결정 3 | + 최대 체력 20% 보호막 |

- 결정 소환 후 10초 안에 파괴하지 못하면 보스가 흡수해 강화
- 파괴한 결정은 강화 단계에 포함되지 않음 (흡수한 결정 수 기준 강화)
- 플레이어 제재가 아닌 보스 강화 방식
- 프로토타입 적용 대상: 하위 신 (권속 적용 여부 확정 필요)

### 7.3 프로토타입 보스

| 구분 | 보스 | 출처 | 패턴 방향 (제안) |
|---|---|---|---|
| 권속 | 우사(雨師)·풍백(風伯) 2인 1조 | 단군신화. 환웅을 따라 내려온 비와 바람의 신 | 공통 패턴 + 우사: 비(감속) / 풍백: 바람(넉백) |
| 하위 신 | 이랑진군(二郎眞君) | 『서유기』 등. 손오공을 사로잡은 천계의 무신 | 삼첨양인도 연속 베기, 효천견 돌진, 이마의 제3의 눈 광선, 격 수확 패턴 |

- 이랑진군: 『서유기』에서 손오공과 변신술 대결 끝에 손오공을 사로잡은 신 → 손오공의 길과 이어지는 서사
- 단군신화의 운사는 제외

#### 우사·풍백 구조

AI 코드 1개 공유, 보스별 데이터로 효과 분리

| 구분 | 우사 | 풍백 | 공유 여부 |
|---|---|---|---|
| AI (이동·거리 유지·패턴 선택) | 동일 | 동일 | 공유 |
| 패턴 구성 (공격 종류·순서·쿨타임) | 동일 | 동일 | 공유 |
| 공격 이펙트 | 비 (물방울, 푸른색) | 바람 (회오리, 흰색) | 데이터 분리 |
| 공격 효과 | 감속 | 넉백 | 데이터 분리 |

| 상황 | 변화 |
|---|---|
| 둘 다 생존 | 기본 패턴 |
| 한 명 처치 | 남은 쪽 공격 속도 증가 + 쓰러진 쪽 효과까지 함께 사용 (예: 우사 생존 시 비 공격에 넉백 추가) |

- 구현: 상대 사망 이벤트 수신 시 데이터 교체
- 플레이 의도: 먼저 처치할 대상 선택, 체력 분배 전략
