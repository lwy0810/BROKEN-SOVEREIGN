# QA 체크리스트

BrokenSovereign 프로토타입 QA 항목. 일정·우선순위 기준은 `GDD.md` 14장 QA 참고.

## 사용 방법

- 회차: A = alpha (10/21), 1 = 1차 (10/24), 2 = 2차 빌드 (10/25), F = 최종 (10/26)
- 결과 칸에 회차별 `O`(통과) / `X`(실패, 이슈 ID 기재) / `-`(해당 없음) 기록
- 실패 항목은 노션 이슈 트래커에 버그로 등록 (재현 절차·기대·실제·관련 파일)
- (예정) 표시는 아직 구현 전 기능. 해당 회차에 구현되어 있으면 점검
