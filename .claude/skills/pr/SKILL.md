# PR 만들기

1. `Docs/Rules/CommitRules.md`를 읽습니다.
2. 현재 브랜치 이름이 규칙에 맞는지 확인합니다. 맞지 않으면 멈추고 알립니다.
3. 커밋하지 않은 변경이 남아 있으면 PR을 만들기 전에 알립니다.
4. `git log main..HEAD`로 이 브랜치에 쌓인 커밋을 확인합니다.
5. PR 제목과 본문을 써서 보여 주고 승인을 받습니다.
   - 제목: 규칙 문서의 `[Type] 요약` 형식
   - 본문: 무엇을 바꿨는지, 왜 바꿨는지, 어떻게 확인했는지
6. 승인을 받으면 `git push -u origin <브랜치 이름>`으로 브랜치를 올리고 `gh pr create --base main --title "<제목>" --body "<본문>"`으로 PR을 만듭니다.
7. 만든 PR의 주소를 알려 줍니다.

머지는 이 스킬이 하지 않습니다. 팀원이 GitHub에서 변경 내용을 확인한 뒤 머지합니다.
