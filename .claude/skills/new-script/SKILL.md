# 새 스크립트 만들기

1. `Docs/Rules/NamingRules.md`와 `Docs/Rules/FolderRules.md`를 읽습니다.
2. 아래 내용을 계획으로 보여 주고 승인을 받습니다.
   - 스크립트 이름과 둘 폴더
   - 필드와 메서드 목록, 각각 하는 일
   - 새로 만들어야 하는 폴더가 있으면 그 폴더
3. 승인을 받으면 스크립트를 만듭니다. 기능은 요청받은 만큼만 채웁니다.
4. `convention-checker` 에이전트에게 만든 파일을 점검받고, 결과를 함께 보고합니다.
5. 만든 컴포넌트를 씬의 오브젝트에 붙이는 일은 에디터 변경이므로 승인을 받기 전에는 하지 않습니다. 어느 오브젝트에 붙이면 되는지만 안내합니다.
